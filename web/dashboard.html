How It Works

1. Monitor — Agent checks all ML training jobs using check_job_status()

2. Detect — Anomaly detection flags jobs with high loss + low progress

3. Learn — Agent reads past decisions from history before acting

4. Act — Restarts failed/stalled jobs with justified reasoning

5. Evaluate — LLM-as-Judge scores every decision 1-10

6. Improve — Scores improve across scenarios as agent learns
